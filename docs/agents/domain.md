# Domain docs

Use one glossary and one ADR directory for the Instagram analytics project, which spans the monorepo’s applications and shared libraries.

- Read the root `GLOSSARY.md` before working on the domain, when the file exists. Use its terminology in code, tickets, and design discussions.
- Read relevant ADRs in `docs/adr/` before changing the corresponding design. Flag conflicts and reconcile them before proceeding.
- Create or update glossary entries when terminology is settled. Record durable technical decisions and their trade-offs in ADRs.
