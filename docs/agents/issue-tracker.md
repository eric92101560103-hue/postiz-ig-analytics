# Issue tracker

Use GitHub Issues in `eric92101560103-hue/postiz-ig-analytics` for tickets and specs. Pass `--repo eric92101560103-hue/postiz-ig-analytics` to `gh issue` commands so they target the fork.

- Create with `gh issue create` and use `--body-file` for multiline text.
- Read with `gh issue view <number> --json number,title,body,labels,comments`.
- Find, update, comment on, or close tickets with `gh issue list`, `gh issue edit`, `gh issue comment`, and `gh issue close`.
- Use GitHub sub-issues and dependencies to record related and blocked work.
